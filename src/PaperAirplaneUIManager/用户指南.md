# PaperAirplane UI 管理器用户指南

## 项目概述

PaperAirplane UI Manager 是一个基于 MFC 的图形用户界面程序，用于管理 PaperAirplane relay server 的配置。它提供了全面的界面来配置代理设置、管理过滤规则和监控 socket 连接。

## 主要功能

### 1. Socket 映射显示
- 实时显示当前活动的 socket 连接
- 显示 socket 句柄、进程 ID、进程名称、本地/远程地址和连接状态
- 统计发送/接收的字节数（可扩展）

### 2. 配置编辑
- **EnableProxyClient**: 启用/禁用代理客户端功能
- **ResolveDNSRemote**: 启用/禁用远程 DNS 解析
- **ProxyHostAddress/ProxyHostPort**: 配置代理服务器地址和端口（默认：127.0.0.1:1080）

### 3. 过滤规则管理
- **FilterPortNumber**: 添加/删除要过滤的端口号
- **FilterHostAddress**: 添加/删除要过滤的 IP 地址
- **FilterHostName**: 添加/删除要过滤的主机名

### 4. 白名单/黑名单编辑
- **黑名单**: 添加不应使用代理的进程（进程路径）
- **白名单**: 添加可以使用代理的进程（备用功能）

### 5. 配置导出/导入
- 导出当前配置到 .pap 文件
- 从 .pap 文件导入配置
- 配置文件使用二进制格式以提高效率

### 6. 热加载配置
- 通过共享内存立即应用更改
- 使用 Windows 命名共享内存：`PAPERAIRPLANE_CONFIGURATION_MAP`
- 通过事件通知 relay server：`PAPERAIRPLANE_CONFIGURATION_EVENT`
- 无需重启应用程序或服务

### 7. 日志/状态显示
- 实时连接状态显示（已连接/未连接）
- 所有操作的事件日志记录
- Connected/Disconnected 回调处理
- 带时间戳的日志条目

## 构建项目

### 系统要求
- Visual Studio 2015 或更高版本（推荐 2017）
- Windows SDK 10.0 或更高版本
- MFC 库（随 Visual Studio 安装）

### 构建步骤
1. 在 Visual Studio 中打开 `PaperAirplaneUIManager.sln`
2. 选择所需的配置（Debug/Release）和平台（Win32/x64）
3. 构建解决方案（Ctrl+Shift+B）

编译后的可执行文件将位于 Debug 或 Release 文件夹中。

## 使用说明

### 初始设置
1. 运行 PaperAirplaneUIManager.exe
2. 应用程序会自动创建共享内存和事件对象
3. 如果 relay server 已加载（通过 LSP/NSP），状态将显示"已连接"

### 配置代理设置
1. 勾选"Enable Proxy Client"以激活代理功能
2. 输入代理主机地址（例如：127.0.0.1）
3. 输入代理端口（例如：1080 用于 SOCKS5）
4. 可选择勾选"Resolve DNS Remote"进行远程 DNS 解析
5. 点击"Apply Configuration"热加载设置

### 管理过滤器
- **端口过滤器**: 在输入框中输入端口号并点击"Add"。选择项目后点击"Remove"删除。
- **地址过滤器**: 输入 IP 地址（例如：192.168.1.1）并点击"Add"
- **主机名过滤器**: 输入主机名（例如：example.com）并点击"Add"

### 管理进程列表
- **黑名单**: 点击"Add"浏览可执行文件。选定的进程将不使用代理。
- **白名单**: 与黑名单类似，但用于允许特定进程（预留功能）

### 导入/导出
- **导出**: 点击"Export Configuration"并选择保存位置保存 .pap 文件
- **导入**: 点击"Import Configuration"并选择 .pap 文件加载

## 技术架构

### 共享内存协议
UI Manager 通过共享内存与 relay server DLL 通信：

```
消息格式：
[4 字节] 消息 ID（每次更新递增）
[1 字节] EnableProxyClient
[1 字节] ResolveDNSRemote
[4 字节] ProxyNotifyHWnd（回调的窗口句柄）
[2 字节] FilterPortNumber 计数
  [N * 2 字节] 端口号
[2 字节] FilterHostAddress 计数
  [N * 4 字节] IP 地址（网络字节序）
[2 字节] FilterHostName 计数
  [N 条目] [2 字节长度][字符串] 主机名
[2 字节] 黑名单进程计数
  [N 条目] [2 字节长度][字符串] 进程路径
```

### 窗口消息
UI Manager 通过 Windows 消息从 relay server 接收通知：
- `PAPERAIRPLANE_PROXECONNECT_MESSAGE (0x1311)`: 代理连接请求
- `PAPERAIRPLANE_PROXEBINDCONN_MESSAGE (0x1312)`: 代理绑定请求
- `PAPERAIRPLANE_PROXECLOSECONN_MESSAGE (0x1313)`: 代理关闭通知

## 故障排除

### 状态显示"未连接"
- 确保 PaperAirplane relay server DLL 已安装并加载
- 检查没有其他应用程序使用共享内存名称
- 验证 Windows 权限允许创建命名对象

### 配置未应用
- 更改后点击"Apply Configuration"
- 检查日志中的错误消息
- 确保您具有管理员权限（如果需要）

### 过滤器不起作用
- 验证过滤器语法（IP 地址、端口号）
- 检查 EnableProxyClient 是否已启用
- 查看 relay server 日志以了解过滤器处理情况
